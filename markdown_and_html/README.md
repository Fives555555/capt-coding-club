## Markdown
Markdown is needed for things like README files. It's simple way to make nice looking text for things like your GitHub repositories. It is also used as a less-verbose markup language (so you don't have to write in HTML).

Try looking at the raw files of READMEs on GitHub for insight into how they work.

Here is a [Markdown Cheatsheet](https://www.markdownguide.org/cheat-sheet/)


## HTML
HTML contains content of webpages and helps to structure it. It has ways of formatting text, images, links, etc. so it can be rendered by web browsers.

Here is an [HTML Cheatsheet](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements)
